2. マップ本体（掲載研究・カテゴリ）の更新

  1. 公式ページ（saqra.jp/kaihatsumap）が更新された場合: ブラウザで「ページのソースを保存」し、python3 tools/import_kaihatsumap.py 保存したファイル.html で map.json を再生成
  2. 個別に直す場合: リポジトリの saqra-map/frontend/data/map.json を編集（"study": null が「ー」＝未実施の行）
  3. ./deploy.sh を実行（map.json のアップロードと外部データの再収集まで自動）
