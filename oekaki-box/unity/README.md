# Cluster の美術館ワールドに、作品を飾る(Unity)

届いた作品を、タイトル・作者・コメント付きで飾ります。
- **2D**:額縁に入れて、壁に(額縁を置く壁: 15 か所)
- **3D**:台座の上に(台座: 10 か所)。説明板も一緒に

**Unity のスクリプトは、まだ実機で動かしていません。** 最初は、テスト用のワールドで試してください。

## 全体の流れ
1. 手元の Mac で、飾る作品と飾り方を選んで、展示用のファイルを作る(`tools/export_for_unity.py`)
2. Unity に、ファイルとスクリプトを入れて、メニューから並べる
3. Cluster Creator Kit で、いつもどおりワールドをアップロードする

## 1. 展示用のファイルを作る(Mac)
```bash
cd ~/AHanaiLab.github.io/oekaki-box
pip3 install pillow
./fetch.sh                                   # 最新の作品を取り込む
python3 tools/export_for_unity.py curate     # 飾る作品を選ぶ表を作る
```
`unity_export/curation.csv` を、Excel かスプレッドシートで開いて、直します。

| 列 | 内容 |
|---|---|
| **展示方法** | `額縁`(2Dだけ) / `3D`(3Dだけ) / `両方` / `N`(飾らない)。3Dがない作品は、`額縁` か `N` だけ |
| **額縁の番号** | 何番の壁に飾るか(1〜15)。**空欄なら、順番に自動で割り当て** |
| **台座の番号** | 何番の台座に飾るか(1〜10)。空欄なら自動 |
| **タイトル・ニックネーム・コメント** | 誤字などを直せます。タイトルが空の作品は、「無題」と表示されます |

- 初めの値は、3Dがある作品が `両方`、ない作品が `額縁` です。**枠(額縁15・台座10)を超えると、`curate` が警告を出して、`build` がエラーで止まります。**「展示方法」を `N` にするなどして、枠に収めてください。
- **不適切な内容や、個人情報が入ったコメントは、ここで外すか、書き換えてください。**
- 番号が重なったり、範囲の外だったりすると、`build` がエラーで教えます。
- 枠の数を変えるときは、`--frames 15 --pedestals 10` で指定します。
- もう一度 `curate` を実行しても、直した内容は消えません。新しく届いた作品だけが、表に足されます。

直したら、保存して、次を実行します。
```bash
python3 tools/export_for_unity.py build
```
`unity_export/` に、`Works` フォルダと `works.json` ができます。
- 絵(`art.png`)と、説明板(`plate.png`。タイトル・作者・コメントを画像にしたもの)
- 3D:`model.obj` と `model_tex.jpg`。**Tripo の GLB を、Unity にそのまま入る形に変換**します(足元の中心が原点、高さ 1)。追加のパッケージは要りません。
- 最後に、合計の大きさと、3Dの三角形の合計が出ます。ワールドの上限と、見比べてください。

ワールドを軽くしたいときは、`--max-size 768`(絵)や `--model-tex-size 512`(3Dの色の画像)を付けます。

## 2. Unity で飾る
1. `Works` フォルダと `works.json` を、Unity の `Assets/OekakiWorks/` に入れます。
2. `unity/Editor/OekakiGalleryBuilder.cs` を、`Assets/Editor/` に入れます。
3. **額縁のプレハブ**を作ります(最初の1回だけ)。
   - 空の GameObject を作って、`OekakiFrame` と名前を付けます。
   - その子に、Quad を2つ作って、名前を `Picture` と `Plate` にします。
   - (任意)額縁の見た目に、薄い Cube を子に作って、`Frame` と名前を付けます。絵の後ろに置くと、絵の大きさに合わせて、自動で伸び縮みします。
   - Project にドラッグして、プレハブにします。
4. **材質**を1つ用意します(`Create > Material`)。絵・説明板・3Dのすべてに、この材質をもとに使います。色がそのまま出る Unlit 系がおすすめです(3Dは、明るさの影響を受けたいなら、Standard など)。**Cluster のワールドで使えるシェーダーかは、Creator Kit の案内で確認してください。**
5. **置き場所**を決めます。
   - **額縁**:空の GameObject の子に、空の GameObject を15個並べて、壁に置きます。**上から1番、2番、…**の順です。向きは、**青い矢印(Z軸)が壁の方向**になるようにします。
   - **台座**:同じように、10個並べて、台座の上面の中心に置きます。説明板を出したいときは、各台座の子に、`PlateAnchor` という空の GameObject を作って、説明板を置く位置と向きに合わせます。
   - 何もしないと、一列に並びます。(試すときに便利です。)
6. メニューの **Oekaki > ギャラリーを作る** を開いて、材質、額縁のプレハブ、置き場所の親を選んで、ボタンを押します。
   - 作品が増えたら、手順 1 の `curate` と `build` をやり直して、`Works` と `works.json` を入れ替えて、もう一度ボタンを押します。(前のものは、消えて、作り直されます。)
   - 絵が見えない、または裏向きのときは、置き場所の向きを 180 度回してください(Quad は、片面しか見えません)。
   - 3Dが鏡写しや、裏返しに見えるときは、教えてください。変換の向きを直します。

## 3. アップロード
いつもの Cluster Creator Kit の手順で、ワールドをアップロードしてください。

## 確認してほしいこと(私が確認できていないもの)
- **Cluster の制限**:ワールドの容量、画像の大きさ、ポリゴン数、使えるシェーダーの上限は、公式の情報を調べても、見つかりませんでした。Creator Kit の案内で確認してください。
  - 3Dは、1体あたり、最大で約3万の三角形です(Tripo の設定)。10体で、約30万です。重いときは、Tripo の設定の `face_limit` を下げます。
- **Unity と Creator Kit のバージョン**:スクリプトは、標準的な Unity の機能だけを使っています。バージョンで動かない場合は、エラーの内容を教えてください。
- **3D変換**:Tripo の GLB は、1つの形と、1枚の色の画像でできている前提です。変換に失敗すると、どの作品かと理由を、教えてくれます。

## 展示について
- 作品、ニックネーム、コメントは、美術館に公開されます。飾る作品を選ぶとき(`curate` の表)に、内容を必ず確認してください。
