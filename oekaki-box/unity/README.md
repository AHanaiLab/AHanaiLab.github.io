# Cluster の美術館ワールドに、作品を飾る(Unity)

届いた作品を、タイトル・作者・コメント付きで、額縁に入れて飾ります。
**Unity のスクリプトは、まだ実機で動かしていません。** 最初は、テスト用のワールドで試してください。

## 全体の流れ
1. 手元の Mac で、展示する作品を選んで、展示用のファイルを作る(`tools/export_for_unity.py`)
2. Unity に、ファイルとスクリプトを入れて、メニューから額縁を並べる
3. Cluster Creator Kit で、いつもどおりワールドをアップロードする

## 1. 展示用のファイルを作る(Mac)
```bash
cd ~/AHanaiLab.github.io/oekaki-box
pip3 install pillow
./fetch.sh                                   # 最新の作品を取り込む
python3 tools/export_for_unity.py curate     # 展示する作品を選ぶ表を作る
```
`unity_export/curation.csv` を、Excel かスプレッドシートで開いて、直します。
- **「展示する」**:`Y`(展示する)か `N`(展示しない)。**不適切な内容や、個人情報が入ったコメントは、ここで外してください。**
- **「タイトル」「ニックネーム」「コメント」**:誤字などを直せます。タイトルが空の作品は、「無題」と表示されます。

直したら、保存して、次を実行します。(もう一度 `curate` を実行しても、直した内容は消えません。新しく届いた作品だけが、表に足されます。)
```bash
python3 tools/export_for_unity.py build
```
`unity_export/` に、`Works` フォルダと `works.json` ができます。作品ごとに、絵(`art.png`)と、説明板(`plate.png`)が入ります。説明板は、タイトル・作者・コメントを、画像にしたものです。

- ワールドを軽くしたいときは、`--max-size 768` を付けます(作品の絵が、小さくなります)。
- 3D(GLB)も出したいときは、`--with-3d` を付けます。(今の飾り方スクリプトは、3Dを使いません。下の「3Dについて」を参照。)

## 2. Unity で飾る
1. `Works` フォルダと `works.json` を、Unity の `Assets/OekakiWorks/` に入れます。
2. `unity/Editor/OekakiGalleryBuilder.cs` を、`Assets/Editor/` に入れます。
3. **額縁のプレハブ**を作ります(最初の1回だけ)。
   - 空の GameObject を作って、`OekakiFrame` と名前を付けます。
   - その子に、Quad を2つ作って、名前を `Picture` と `Plate` にします。
   - (任意)額縁の見た目に、薄い Cube を子に作って、`Frame` と名前を付けます。絵の後ろに置くと、絵の大きさに合わせて、自動で伸び縮みします。
   - Project にドラッグして、プレハブにします。
4. **材質**を1つ用意します(`Create > Material`)。シェーダーは、色がそのまま出る Unlit 系がおすすめです。**Cluster のワールドで使えるシェーダーかは、Creator Kit の案内で確認してください。**
5. 絵を飾る位置を決めます。
   - **簡単**:何もせずに、一列に並べる(最初の位置と間隔を、画面で指定)。
   - **きれいに**:空の GameObject を作って、その子に空の GameObject を作品の数だけ並べて、飾りたい場所に置きます。向きは、**青い矢印(Z軸)が、壁の方向**になるようにします。
6. メニューの **Oekaki > ギャラリーを作る** を開いて、作品のフォルダ、額縁のプレハブ、材質を選んで、ボタンを押します。
   - 作品が増えたら、手順 1 の `curate` と `build` をやり直して、`Works` と `works.json` を入れ替えて、もう一度ボタンを押します。
   - 絵が見えない、または裏向きのときは、置き場所の向きを 180 度回してください(Quad は、片面しか見えません)。

## 3. アップロード
いつもの Cluster Creator Kit の手順で、ワールドをアップロードしてください。

## 確認してほしいこと(私が確認できていないもの)
- **Cluster の制限**:ワールドの容量、テクスチャの大きさ、使えるシェーダーの上限を、Creator Kit の案内で確認してください。作品が多いときは、`--max-size 768` や、画像の最大サイズ 512 で、軽くします。目安:1作品あたり、絵と説明板で、約 0.2〜0.5 MB です。
- **Unity と Creator Kit のバージョン**:スクリプトは、標準的な Unity の機能だけを使っています。バージョンで動かない場合は、エラーの内容を教えてください。

## 3Dについて
3D(GLB)を飾るには、別の手間があります。ワールドに入れるには、Unity に取り込んだ形(FBX など)にして、台座などに置く必要があります。ポリゴン数(今は3万まで)や、テクスチャの重さも、ワールドの上限に関わります。2Dの展示が動いてから、一緒に進めましょう。

## 展示について
- 作品や、ニックネーム、コメントは、美術館に、公開されます。展示する作品を選ぶとき(`curate` の表)に、内容を、必ず確認してください。
- 参加者に、展示の方法(額縁に入れて飾る)と、名前の出し方(ニックネーム)を、先にお知らせしておくと安心です。
