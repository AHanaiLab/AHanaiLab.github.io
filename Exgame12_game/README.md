# Squat Battle（Exgame12 ゲームモード単体版）

[Exgame12](../Exgame12/) の「⚔️ ゲームモード」だけを切り出した単体ページです。

公開URL: https://ahanailab.github.io/Exgame12_game/

## 違い（Exgame12 との比較）

- ゲームモードのみ（スロトレ / セルフ / CS-30 / バランス / バンザイ は無し）
- ID・身長・体重の入力なし
- 事後評価なし（アンケート / 推定値 / グラフ を表示しない）
- 事後保存なし（クラウド送信 / CSV ダウンロード をしない）
- 終了時はスクワット実施回数だけを「がんばったね！」と表示する

## 使い方

1. 「スタート」を押してカメラを許可する
2. 横向きに立つと 5 秒カウントダウン後に開始
3. スクワットでモンスターの HP を削る（深くしゃがむとクリティカル）
4. Lv.5 を倒すか「終了」を押すと回数を表示
